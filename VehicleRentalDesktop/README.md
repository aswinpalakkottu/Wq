# 🚗 Cerero Vehicle Rental System

A comprehensive desktop application for managing vehicle rentals built with Java Swing and MySQL.

## 📋 Project Overview

The Vehicle Rental System is a robust desktop application that automates and streamlines the entire vehicle rental process. It provides separate interfaces for customers and administrators with complete rental management capabilities.

## ✨ Features

### 👥 Customer Features
- **User Registration & Login** - Secure customer accounts
- **Browse Vehicles** - View available cars, bikes, and scooters
- **Vehicle Search** - Filter and find suitable vehicles
- **Online Booking** - Reserve vehicles for specific dates
- **Rental History** - View past and current rentals
- **Digital Bills** - Automated bill generation

### 🔧 Admin Features
- **Vehicle Management** - Add, remove, and update vehicles
- **Customer Management** - View all registered customers
- **Rental Monitoring** - Track all active and completed rentals
- **Inventory Control** - Manage vehicle availability
- **Admin Dashboard** - Comprehensive system overview

### 🛠️ Technical Features
- **MySQL Database** - Persistent data storage
- **Object-Oriented Design** - Clean, maintainable code architecture
- **Java Swing GUI** - User-friendly desktop interface
- **Data Validation** - Input validation and error handling
- **Secure Authentication** - Password-protected access

## 🛠️ Technology Stack

- **Backend**: Java 8+
- **Frontend**: Java Swing
- **Database**: MySQL 8.0+
- **Database Driver**: MySQL Connector/J 8.0+
- **Build Tool**: Java Compiler (javac)
